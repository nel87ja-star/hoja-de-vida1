# Hoja de vida web

Sitio profesional responsive para Nelson Saul Chiluisa, construido únicamente con HTML5, CSS3 y JavaScript Vanilla.

## Estructura

```text
index.html
css/styles.css
js/script.js
docs/Hoja_de_Vida_Nelson_Chiluisa.pdf  # archivo que debes agregar
img/perfil.jpg                         # fotografía opcional
```

## Personalización rápida

- **Fotografía:** reemplaza el bloque reservado en `index.html` por una imagen en `img/perfil.jpg`.
- **Correo:** reemplaza `[Pendiente de agregar]` y agrega un enlace `mailto:` en la sección de contacto.
- **Perfil, experiencia, estudios y cursos:** edita los textos marcados como `[Campo editable]`, `[Contenido editable]` o `[Pendiente]`.
- **Reconocimientos, idiomas, referencias y redes sociales:** completa las tarjetas de información adicional.
- **Descarga:** coloca el archivo real en `docs/Hoja_de_Vida_Nelson_Chiluisa.pdf`; el botón ya apunta a esa ruta.

## Funcionalidades

Incluye menú hamburguesa responsive, scroll suave, navegación activa, animaciones al desplazarse, tema claro/oscuro persistido en `localStorage`, botón volver arriba, enlaces de llamada y WhatsApp, y validación local del formulario. El formulario no envía correos hasta conectarlo a Formspree, EmailJS o un backend.

## Ejecución

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático local. No requiere instalación de dependencias.
